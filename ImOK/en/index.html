I'm OK: Daily Check-in

A daily check-in to share your status with the people you choose, from the app, widget or shortcut.

Situations where it may fit

If you want to know whether an older parent who lives alone has checked in, let your family know during a trip, or share an “I'm OK” message when going out for a solo workout, the app combines a manual check-in, selected contacts, messages and local notifications. You can also use a message such as “I've arrived” when you get home. It is not an emergency service, and the code does not guarantee delivery.

How it works

The flow found in the code combines a manual confirmation, a shared CloudKit record and local notifications.

1

Set up your account and contacts

The app asks for a display name, Contacts access to choose a person and an iCloud account to share the status. The invitation is a CloudKit link.

2

Confirm your status

Tap the main button, widget, Siri/Shortcuts intent or system quick action. You can add a message, photo or the one-shot “I'm Here” location status.

3

The contact syncs and can view it

The status is stored as DailyStatus in CloudKit. An invited contact can sync it, open it, mark it as viewed and chat.

How the alert is shared

The route depends on the mode used and what is enabled on each device.

  • Apple/iCloud: CKShare with read/write permission on a DailyStatus record.
  • Push: CloudKitSubscription with a silent payload to refresh the app in the background.
  • Visible alert: created locally by UserNotifications on the contact's device.
  • SMS/WhatsApp: system share sheet or SMS composer started manually by the user.

Important limit

The repository contains no own backend, WhatsApp SDK or code that automatically sends an SMS alert to a family member when the deadline passes. The implemented “Safety Auto-Warning” is a local notification scheduled on the device that already has the shared status.

The website therefore does not describe the flow as a guarantee or as a replacement for emergency services.

What can prevent an alert

The app does not control the network, device state or system permissions.

Phone is off

There is no code that independently sends an SMS/WhatsApp alert when the confirming person's phone is off. If the contact's device already synced the status, its local timer may still fire; that depends on the receiving device, iOS and its permissions.

No network

CloudKit needs connectivity to save and sync the latest change. The code shows an optimistic local update, but does not implement a persistent send-retry queue.

Notifications disabled

If iOS has not authorized alerts, sound or badges, local notifications are not shown. Content may still appear when the app opens and syncs.

Frequently asked questions

Direct answers based on the repository and App Store listing consulted.

How does the alert reach my family?
The code stores the status in CloudKit and shares it through a CKShare. The contact's device syncs the status through CloudKit and may receive a silent push to refresh the app; the app creates the visible notification locally. There is no own server sending an automatic SMS or WhatsApp message.
What data leaves the device?
DailyStatus and Message records can go to CloudKit, and an optional photo can be sent as a CKAsset. The name, message, date, viewers, warning threshold and, when used, a one-shot location are included according to the flow used.
Does it work without iCloud?
The code needs an available iCloud account for the main sharing flow. When it is unavailable, the app shows an iCloud-required screen; local data may remain while synchronization is pending.
What does the absence warning do?
A shared status can include a 24, 25, 30, 36 or 48-hour threshold. The device that received the status schedules a local notification when the threshold passes; the code also checks when syncing whether the threshold has passed.
Does the app automatically send SMS or WhatsApp?
That automatic send does not appear in the code. The user opens an SMS composer or system share sheet, chooses a channel and confirms the action. The app cannot confirm delivery or reading in the external channel.
Does it use GPS in real time?
There is no continuous location in the project. Location is requested only when sending the one-shot “I'm Here” message, with When In Use permission.
What does the widget show?
The small and medium widget shows pending, sent or viewed, the time, viewer names and, if enabled, a compressed photo. Tapping it opens the app.
What is the price?
iTunes returns €0.99 as the download price. It remains marked as pending confirmation. No StoreKit or in-app-purchase code was found in the project.
