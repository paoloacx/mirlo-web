Weather, with context.

Weather for humans combines live weather data with local calculations for daylight, moon phases, historical comparisons, clothing suggestions and weather-aware notices.

  • Read current temperature, feels-like temperature, high and low temperatures, humidity, wind, cloud cover and precipitation.
  • See the next hours, tomorrow and up to ten forecast days in the app’s forecast views.
  • Compare today with historical daily data and inspect monthly climate summaries.
  • Open detailed views for temperature, wind, sky conditions, daylight, moon and tomorrow.

How it works

The implementation stores a selected place locally, fetches weather for its coordinates, derives context on the device, and shares a snapshot with widgets.

  1. Search a place with MapKit suggestions, or allow a one-time current-location request.
  2. Request weather data for the selected coordinates through WeatherKit.
  3. Use historical WeatherKit data, with an Open-Meteo Archive API fallback in historical calculations.
  4. Save weather summaries and widget data locally, then refresh the app and widgets when data changes.

Frequently asked questions

Direct answers based on the current project and the App Store listing.

What does Weather for humans show?
It shows current conditions, feels-like temperature, high and low temperatures, humidity, wind, cloud cover, precipitation, daylight, moon information, hourly forecasts, multi-day forecasts and historical context.
What weather services does it use?
The app requests current, hourly, daily, alert and historical weather data from Apple WeatherKit. The code also contains an Open-Meteo Archive API fallback for historical daily data and climate calculations.
Does the app use my location?
You can search for a place and save its coordinates. The app also has an optional current-location flow that requests When In Use location permission, reverse-geocodes the result and uses the coordinates to request weather.
Does it send weather notifications?
The code supports local notifications for daily summaries, tomorrow outlooks, rain, snow, frost, tropical nights, wind, temperature changes and severe weather settings.
Which languages are available?
The project contains English and Spanish localizations. The App Store lookup also reports EN and ES language codes.
Is there a premium mode?
Yes. Premium features include extra saved locations, automatic GPS in the settings flow, more forecasts, climate views, widgets and dashboard customization.
What does premium cost?
Premium costs €0.99 per week, €19.99 per year, or €39.99 one-time lifetime.
