El tiempo, con contexto.

Weather for humans combina datos meteorológicos con cálculos locales de luz diurna, fases lunares, comparaciones históricas, sugerencias de ropa y avisos relacionados con el tiempo.

  • Consulta temperatura, sensación térmica, máximas y mínimas, humedad, viento, nubosidad y precipitación.
  • Consulta las próximas horas, mañana y hasta diez días en las vistas de previsión de la app.
  • Compara el día con datos históricos y consulta resúmenes climáticos mensuales.
  • Abre detalles de temperatura, viento, cielo, luz diurna, luna y mañana.

Cómo funciona

La implementación guarda una localidad seleccionada, pide el tiempo para sus coordenadas, calcula contexto en el dispositivo y comparte una instantánea con los widgets.

  1. Busca una localidad con sugerencias de MapKit o permite una petición puntual de ubicación actual.
  2. Solicita datos meteorológicos para las coordenadas seleccionadas mediante WeatherKit.
  3. Usa históricos de WeatherKit y un fallback a la API Archive de Open-Meteo en los cálculos históricos.
  4. Guarda resúmenes y datos de widgets localmente y los actualiza cuando cambian los datos.

Preguntas frecuentes

Respuestas directas basadas en el proyecto actual y en la ficha de la App Store.

¿Qué muestra Weather for humans?
Muestra las condiciones actuales, sensación térmica, máximas y mínimas, humedad, viento, nubosidad, precipitación, luz diurna, información lunar, previsiones por horas, previsiones de varios días y contexto histórico.
¿Qué servicios meteorológicos utiliza?
La app solicita datos actuales, horarios, diarios, avisos e históricos a Apple WeatherKit. El código también contiene un fallback a la API Archive de Open-Meteo para datos diarios históricos y cálculos climáticos.
¿Utiliza mi ubicación?
Puedes buscar una localidad y guardar sus coordenadas. La app también tiene un flujo opcional de ubicación actual que solicita permiso de ubicación en uso, obtiene un nombre mediante geocodificación inversa y usa las coordenadas para pedir el tiempo.
¿Envía avisos meteorológicos?
El código admite notificaciones locales para resúmenes diarios, previsión de mañana, lluvia, nieve, heladas, noches tropicales, viento, cambios de temperatura y ajustes de tiempo severo.
¿Qué idiomas están disponibles?
El proyecto contiene localizaciones en inglés y español. La consulta a la App Store también devuelve los códigos de idioma EN y ES.
